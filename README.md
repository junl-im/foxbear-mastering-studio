# FoxBear AI Mastering Studio Pro v1.3.79

## v1.3.79 Dock Purpose Realignment

- Dock 통합 파형을 단순 진행 막대가 아니라 **피크 위치를 읽는 정보형 파형**으로 다시 조정했습니다.
- 재생 전/후 밝기 차이는 유지하되, 재생 전 구간에서도 노랑/빨강 피크 위험 구간이 보이도록 색 대비를 보강했습니다.
- Dock 플레이어 우측 정보 영역을 작은 2단 파티션으로 나눠 위에는 `원곡/마스터링/하이라이트`, 아래에는 진행 시간/러닝타임이 나오게 했습니다.
- `비교보기` 버튼을 별도 큰 줄에서 제거하고 곡명/장르 표기 줄 우측의 작은 칩으로 이동했습니다.
- Dock 버튼 라인을 3구간으로 정리했습니다: 좌측 `하이라이트 듣기`, 중앙 `마스터링 시작`, 우측 `원곡 프리뷰 / 마스터링 프리뷰`.
- 마스터링 완료 후 작업대기열의 다운로드 버튼 라인이 화면 중앙보다 살짝 위에 오도록 스크롤하고, “여기서 저장” 강조를 표시합니다.
- 다운로드 옵션 팝업의 크기/최대 높이를 보강해 내용이 작게 잘려 보이지 않도록 조정했습니다.
