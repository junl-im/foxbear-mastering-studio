    FoxBear Mastering PRO는 별도 설치 없이 음원을 분석하고, 추천 설정을 확인한 뒤 원본과 비교하며 안전하게 마스터 파일을 만드는 무료 브라우저 스튜디오입니다.

    스마트 분석과 추천장르·음량·다이내믹·보컬·저역·스테레오 특성을 분석해 시작하기 좋은 마스터링 설정을 제안합니다.
    음질 보호 마스터링K-weighted LUFS, True Peak, DC offset, 과도한 밝기·금속성·저역 번짐을 점검하며 자연스러운 결과를 우선합니다.
    듣고 비교하며 조정원본·마스터 A/B, 15초 하이라이트, 파형 비교와 세부 강도 조절로 저장 전 결과를 직접 확인할 수 있습니다.
    일괄 작업과 안전한 저장여러 곡의 대기열·취소·재시도·개별/묶음 저장을 지원하고, WAV·MP3·AIFF PCM 및 브라우저 지원 형식을 제공합니다.

    개인정보 보호: 기본 오디오 분석과 PCM 처리는 기기 안에서 실행되며 원본 음원은 서버로 전송하지 않습니다.

    오류 자동신고

    치명적 오류와 작업 실패의 익명 진단만 Firebase로 전송합니다. 오디오·파일명·전체 로컬 경로는 포함하지 않으며, 익명 진단 정보만 사용합니다.

    전송 대상 수신 주소는 mcwoogi@gmail.com이며, 발신자명은 AI마스터링 스튜디오입니다.
    서버 연결 상태 서버 상태를 확인하지 않았습니다. 호출 함수: getIncidentServiceStatus Functions endpoint를 확인합니다. Hosting same-origin 복구 경로를 확인합니다. 직접 HTTP 도달성: 오류 발생 시 자동 확인 Hosting CSP를 확인합니다. App Check는 사용하지 않는 정책입니다.
    연결 자동 복구 일시적 네트워크·인증 오류는 최대 3회 자동 재확인하며, 실패 신고는 로컬 대기열에 보관합니다.
