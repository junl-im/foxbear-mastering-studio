# v1.5.71 관리자 운영 UI와 메일 기간 추세

## 진행 목표

관리자 오류 화면의 많은 카드와 버튼을 운영 우선순위에 맞게 재구성하고, 실제 메일 테스트를 기간별로 판단할 수 있도록 개선합니다.

## 주요 변경

- 화면 상단에 현재 운영 상태, 마지막 자동 점검, 다음 권장 조치를 보여주는 종합 상태 영역을 추가했습니다.
- 복구, 시스템 검증, 실수신 확인 작업을 세 그룹으로 분리했습니다.
- 중요 상태 카드와 보조 상태 카드의 시각적 우선순위를 구분했습니다.
- 실제 메일 테스트 통계에 최근 7일, 30일, 90일, 전체 기간 선택을 추가했습니다.
- 선택 기간의 최근 14개 테스트를 SMTP 접수, 받은편지함 확인, 스팸함 확인, 실패 상태로 시각화합니다.
- CSV 내보내기는 선택 기간과 검색·상태 필터를 모두 반영합니다.
- 다음 실수신 검증 예정 시각, 검증 경과일, 일정 상태를 서버 운영 문서에도 저장합니다.
- 모바일에서는 상태 카드 2열, 작업 그룹 1열, 버튼 1열로 재배치합니다.
- 표 헤더 고정, 행 강조, 상세 패널 열림 상태 표시와 상태 칩을 적용했습니다.

## 운영 확인

- 관리자 화면의 현재 상태 요약이 SMTP, 정체 큐, 최종 실패, 수신 확인 누락과 배포 상태를 우선순위대로 표시하는지 확인합니다.
- 최근 7일·30일·90일을 바꿀 때 통계, 추세, 목록과 CSV 대상 건수가 함께 바뀌는지 확인합니다.
- 다음 실수신 검증 예정 시각이 마지막 확인 후 7일 기준으로 표시되는지 확인합니다.
- 720px 이하에서 작업 그룹과 버튼이 겹치지 않고 한 열로 표시되는지 확인합니다.

## 제한 사항

실제 Gmail 수신과 Firebase 배포 상태는 배포 권한이 있는 환경에서 별도 확인해야 합니다. 로컬 정적 검사는 UI 계약과 데이터 계산, 자산 세대 및 패키징 무결성을 검증합니다.
