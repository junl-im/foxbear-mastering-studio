# v1.6.39 UI Shell Partial Script Recovery and Probe Isolation

## Scope

This patch hardens partial JavaScript boot failure and service-worker shell-generation collection without changing mastering DSP, encoders, download formats, Firebase document fields, or incident payloads.

## Changes

- Tracks build info, Runtime Health, service-worker update coordination, and the main app bundle as critical scripts.
- Keeps unresolved scripts pending until the window load boundary or an explicit resource error.
- Preserves the static UI and activates one recovery surface when a critical script is confirmed missing.
- Resolves the degraded state when the script later loads successfully.
- Accepts request-bound client shell reports only while the matching service-worker probe is active.
- Re-checks `clients.matchAll()` after the probe window and removes clients that terminated during collection.
- Retries surviving non-responders once with a bounded delay.
- Prunes reports for clients that no longer exist and exposes only aggregate counters in release diagnostics.
