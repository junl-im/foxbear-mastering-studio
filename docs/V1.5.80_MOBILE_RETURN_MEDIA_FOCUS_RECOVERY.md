# v1.5.80 Mobile Return, MediaSession, and Focus Recovery

## Fixed defects

- WebKit may report an `AudioContext` as `interrupted` after screen lock, calls, or app switching. Managed contexts now attempt recovery for every resumable non-running state instead of only `suspended`.
- Concurrent foreground and play-gesture recovery requests now share one native `resume()` operation, preventing duplicate state transitions and noisy failures.
- Dock transport captured for a lifecycle background transition now remains valid for 12 hours instead of expiring after 60 seconds. Ordinary interaction snapshots retain the short safety lease.
- Duplicate `visibilitychange` and `pageshow` restore events are coalesced so the Dock is not rebuilt twice during one foreground transition.
- MediaSession metadata, position state, and action handlers are cleared when no active Dock source exists. Pause and seek handlers resolve the current audio at invocation time instead of retaining a removed element.
- Native share/direct-save completion restores focus to the initiating control, while every assist action, including the file-open link, is disabled during the active native operation.
