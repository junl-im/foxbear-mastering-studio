# v1.6.103 CI hygiene and mail-routing hardening

- Removes the accidental tracked root `README.txt` that blocked the v1.6.102 strict Source Hygiene gate.
- Adds a `mailRouting` deployment-readiness check visible to authenticated administrators. It reports only `env` versus `fallback`; operational email addresses are never returned by this metadata.
- Keeps the existing fallback routing active for compatibility, while warning administrators to configure both `FOXBEAR_ALERT_RECIPIENT` and `FOXBEAR_ALERT_SENDER`.
- Removes eight unused Service Worker share-policy constants so the shared `SHARE_POLICY` module is the single runtime policy source.
