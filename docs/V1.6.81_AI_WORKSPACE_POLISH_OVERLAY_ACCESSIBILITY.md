# v1.6.81 AI Workspace Polish / Overlay Navigation / Accessibility

## Scope

This release does not fork the mastering engine. AI Mastering and Expert mode still use the same track, analysis, mastering, download, playback, and Dock state.

## Changes

- AI Mastering collapses decorative hero content and keeps the compact command bar plus import, queue, analysis, and Dock workflow.
- Optional workspace selection is a shared managed overlay with browser-Back closure; the mandatory first-entry selection intentionally does not add a history sentinel.
- The background app shell is inert while the chooser is open.
- Focusable discovery checks computed visibility so the required hidden close button cannot become a keyboard target.
- Mobile chooser sizing follows the shared visual viewport and uses larger text and targets.

## Acceptance

- First entry requires a workspace choice.
- Same-session refresh restores the selected workspace.
- Reopened chooser closes on Escape, backdrop, close button, or browser Back without leaving the page.
- Mode changes preserve queue, selected track, analysis, mastering result, download state, and Dock playback state.
- Expert mode retains the original full studio layout.
