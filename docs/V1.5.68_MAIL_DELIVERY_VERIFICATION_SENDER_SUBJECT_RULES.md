# v1.5.68 실제 메일 발송 검증 및 제목 규칙

## 목표

- 오류가 없어도 운영자가 실제 Gmail SMTP 발송 경로를 확인할 수 있게 한다.
- 모든 SMTP 메일의 발신자명을 `AI마스터링 스튜디오`로 통일한다.
- 받은편지함 검색과 장애 분류가 쉬운 제목 규칙을 적용한다.

## 메일 규칙

- 발신자명: `AI마스터링 스튜디오`
- 테스트: `[AI마스터링 스튜디오][메일 테스트] 실제 발송 확인 · {테스트 ID}`
- 오류 신고: `[AI마스터링 스튜디오][오류 신고] {긴급|오류|경고} · {분류} · v{버전} · {보고서 ID}`
- 운영 경고: `[AI마스터링 스튜디오][운영 경고] 메일 시스템 점검 필요`
- 긴급 장애: `[AI마스터링 스튜디오][긴급 장애] 메일 시스템 확인 필요`
- 복구 완료: `[AI마스터링 스튜디오][복구 완료] 메일 시스템 정상화`
- 일일 요약: `[AI마스터링 스튜디오][일일 요약] {KST 날짜} · 오류 {건수}건`

## 실제 발송 확인

설정의 `실제 메일 테스트`는 일반 오류 신고와 동일한 Firestore→Cloud Functions→Gmail SMTP 경로를 사용한다. 성공 시 화면에 SMTP 접수 시각, 제목, Message-ID가 표시된다. `emailed`는 Gmail SMTP가 수신자를 승인했다는 뜻이며 받은편지함 도착 위치까지 보장하지는 않으므로 받은편지함·스팸함 검색을 병행한다.

## 배포 후 확인

1. Secret과 Functions를 배포한다.
2. 앱 설정에서 `실제 메일 테스트`를 누른다.
3. 화면에서 `Gmail SMTP 접수 완료`와 제목·Message-ID를 확인한다.
4. Gmail에서 `subject:"[AI마스터링 스튜디오][메일 테스트]"`로 검색한다.
5. 수신되지 않으면 스팸함, Gmail 앱 비밀번호, Cloud Functions 로그를 확인한다.
