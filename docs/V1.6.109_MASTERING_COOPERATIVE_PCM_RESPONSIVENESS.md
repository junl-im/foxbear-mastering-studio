# v1.6.109 Mastering cooperative PCM responsiveness

## Goal

Reduce the short UI freezes that can still occur during long, synchronous PCM scans while keeping the mastering DSP and sample results unchanged.

## Changes

- DC-offset measurement/removal in the main mastering path now runs cooperatively and yields at 65,536-sample checkpoints with a 10ms yield budget.
- Pre-pitch, post-master, final-output, and one-shot quality-recovery safety scans now use the same cooperative sanitizer path.
- The 30-39% mastering range now reflects real DC/safety scan progress instead of jumping directly from 30% to 40%.
- Waveform overview generation now reuses already-calculated waveform bins for peak markers instead of rescanning both PCM buffers a second time.
- The main post-finalizer waveform overview uses an async cooperative sampler so long tracks keep returning control to the browser.
- Cooperative work checks cancellation every 65,536 samples and yields after the default 10ms execution budget is reached.

## Audio integrity

The cooperative functions preserve the legacy loop order and Float32 writes. Regression QA compares the legacy reference algorithm and the new cooperative output sample-for-sample for DC cleanup and sanitizer paths. Waveform values and marker arrays are also required to match the synchronous implementation exactly.

No mastering EQ, dynamics, limiter, loudness target, pitch, finalizer, or encoder DSP coefficients are changed in this release.
