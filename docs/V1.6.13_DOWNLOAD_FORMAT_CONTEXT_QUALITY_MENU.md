# v1.6.13 Download Format Context Quality Menu

## Goal

Simplify the mastered-file download sheet so only MP3 and WAV remain visible. A click on either format opens a compact, anchored quality menu similar to a Windows context menu.

## Behavior

- MP3 menu: 128, 192, 256, and 320 kbps.
- WAV menu: 16-bit PCM, 24-bit PCM, and 32-bit Float.
- The menu opens beside the selected format, uses a vertical list, and marks the current quality with a check.
- Selecting a quality updates the existing selected-format state and closes the menu.
- Clicking the same format again, clicking elsewhere in the dialog, or pressing Escape closes the menu.
- Arrow Up/Down, Home, and End move through available qualities; focus returns to the format button after dismissal.

## Preserved contracts

- No encoder or DSP output changes.
- Same-format Blob reuse remains intact.
- Download, Web Share, save-assist, external-browser, cancellation, timeout, and recovery flows are unchanged.
- Mobile continues to use the full-height bottom sheet while the quality menu remains anchored inside it.
