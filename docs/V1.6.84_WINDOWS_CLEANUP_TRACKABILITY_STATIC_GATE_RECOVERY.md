# v1.6.84 Windows cleanup trackability and Static gate recovery

## Incident

GitHub Actions run #271 for commit `ad53415` failed in the Static release gate. The preceding source-hygiene step also removed tracked `PATCH_MANIFEST.json` from the ephemeral checkout.

The v1.6.83 delivery ZIP contained `APPLY_PATCH_CLEANUP.cmd`, but the repository `.gitignore` still ignored every `*.cmd` file. GitHub Desktop therefore did not stage the new cleanup helper, so the committed repository did not contain the file required by `qa/v1683_browser_gate_ui_mode_fixture_source_hygiene_smoke.js`.

## Recovery

- Preserve the broad `*.cmd` executable-safety rule.
- Add the exact exception `!APPLY_PATCH_CLEANUP.cmd`.
- Require that helper in `HANDOFF_PACKAGE.json`.
- Include `PATCH_MANIFEST.json` in the handoff deletion contract.
- Add a Git-backed regression proving only the approved helper escapes the ignore rule.

## Expected GitHub Desktop delta

After applying the patch and running cleanup, GitHub Desktop must show both `APPLY_PATCH_CLEANUP.cmd` as an added/tracked file and `PATCH_MANIFEST.json` as deleted. Commit both changes in the same release commit.
