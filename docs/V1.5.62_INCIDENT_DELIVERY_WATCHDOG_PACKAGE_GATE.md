# v1.5.62 문제 보고 메일 감시 및 패키지 게이트

## 진행된 내용

- 신규 문제 보고에 명시적 `pending` 전달 상태를 추가했습니다.
- 상태별 Firestore 큐 인덱스와 스케줄 감시를 추가했습니다.
- 워커 임대 ID와 stale completion fencing을 적용했습니다.
- 보고서별 SMTP Message-ID를 고정했습니다.
- 최대 3회 실패는 `dead-letter`로 분리하고 관리자 강제 재전송을 지원합니다.
- 관리자 화면에 최종 실패, 실패 사유, 임대 만료 시각을 표시합니다.
- 릴리스 ZIP 생성 전에 버전과 인수인계 상태를 강제 검사합니다.
- 관리자 강제 재전송이 일일 한도에 걸려도 최종 실패 플래그를 해제하고 다음 자동 재시도를 예약합니다.
- 인수인계 문서에 `진행된 내용 / 배포 파일 2종 / 다음 예상 내용` 보고 형식을 고정했습니다.

- 정적·회귀 검사 270개를 두 구간으로 실행해 모두 통과했습니다.
- Playwright 브라우저 검사는 Chromium 실행 파일이 설치되지 않아 앱 실행 전 단계에서 중단됐습니다.
- 현재 환경에는 Firebase CLI와 실제 프로젝트 배포 권한이 없어 Firestore 규칙·인덱스와 Gmail 수신을 실배포 검증하지 못했습니다.

## 배포 파일 2종

- 전체 릴리스 ZIP
- 누적 덮어쓰기 ZIP

## 다음 예상 내용

- 실제 Firebase 배포 후 인덱스 생성 완료와 Gmail 수신을 확인합니다.
- SMTP Secret 만료·계정 차단을 별도 운영 경보로 분리하는 개선을 검토합니다.
