# v1.6.93 Mobile Dock visibility and integrity recovery

## Incident

On mobile, the bottom preview Dock could appear as an empty shell in AI mode or disappear in both AI and Expert modes even though tracks still existed. This is a critical workflow break because the shared preview transport is the main playback path in both workspaces.

## Root causes

1. `assets/css/ui-mode.css` forced `body[data-ui-mode="ai"] .bottom-preview-dock { display: block; }`. That rule overrode the Dock's base hidden state, so an `aria-hidden="true"` Dock without `.show` could still be rendered as an empty fixed panel in AI mode.
2. `renderBottomPreviewDock()` treated a transient stale `state.selectedId` as equivalent to an empty queue. Direct Dock renders could clear the player, remove `.show`, and drop `bottom-preview-active` even when valid tracks remained.
3. Runtime diagnostics only reported whether a Dock node existed, not whether the Dock was visible, had an active track, or contained a player. An empty or hidden Dock could therefore look healthy in support snapshots.

## Recovery

- AI mode now displays the Dock only when `.show` and `aria-hidden="false"` agree. Hidden or non-`.show` Dock states stay `display:none`.
- Active-track recovery runs before full rendering and before direct Dock rendering. Recovery precedence is the last valid Dock owner, then a valid selected-track ID, then the first remaining track.
- The new `src/ui/bottom-preview-dock-integrity-service.js` owns Dock selection recovery, integrity snapshots, and one-frame repair scheduling without expanding the main app orchestrator past its structural line budget.
- Integrity checks run after Dock rendering and mobile/layout lifecycle events. A Dock expected to be visible is unhealthy if it is hidden, has mismatched ARIA/body state, has zero player children, or has zero rendered height. The service performs at most the bounded requested re-render path and records repair diagnostics.
- Performance diagnostics now include the Dock integrity snapshot and emit `dock-integrity-failed` when the visible transport state disagrees with application state.

## Non-goals

- No mastering DSP, recommendation, loudness, transient, export, or audio-quality profiles were changed.
- v1.6.92 AI Spectrum canvas lifecycle recovery remains intact.
- The Dock is still intentionally hidden when the track queue is actually empty.
