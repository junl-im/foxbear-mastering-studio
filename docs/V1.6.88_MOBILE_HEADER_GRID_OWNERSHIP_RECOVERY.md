# v1.6.88 Mobile Header Grid Ownership Recovery

## Incident

GitHub Actions v1.6.87 left only the `chromium-mobile-pwa` Runtime Health sentinel failing with a strict header row-overlap assertion (`91.96875px > 1px`). Desktop had already recovered.

## Root hardening

The command header already used CSS Grid, but the left rail also inherited historical `.brand-kicker { width: 100% !important; }` rules from older studio generations. v1.6.88 makes the actual grid-item contract authoritative: the left rail owns column 1 with auto width and bounded min/max sizing, while the right action rail owns column 2 and is end-aligned. The compact breakpoint reasserts the same ownership.

This is intentionally stronger than hiding another label: it prevents older width/order rules from changing the measured grid-item bounding boxes.

## Browser contract

The Runtime Health `rowOverlap <= 1px` requirement remains unchanged for both the initial project viewport and the later 320px stress viewport. Diagnostic messages now identify which viewport produced the overlap.
