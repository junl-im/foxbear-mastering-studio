# v1.6.76 Download Viewport + Runtime Fault Diagnostics

## Changes

- Download sheet now follows `visualViewport.height` and keyboard/browser-chrome bottom insets on mobile.
- While encoding, the sticky primary action bar becomes non-sticky so it cannot cover the worker progress card.
- Viewport resize/scroll events re-reveal active encoding progress.
- Added privacy-safe in-memory recoverable fault counters for selected silent fallback paths.
- Performance, download, and incident diagnostics can include bounded category/code counters without messages, stacks, filenames, or user data.

## Instrumented recoverable paths

- download preference storage
- download object URL revocation
- incident localStorage reads/writes
- Firebase admin redirect session storage
- service-worker client-state/channel/storage fallback operations

## Policy

- Counters are memory-only and capped at 48 unique category/code pairs.
- Repeated recoverable faults (3+ in 5 minutes) surface as a performance diagnostic warning.
- No free-form exception message or stack is retained by this counter service.
