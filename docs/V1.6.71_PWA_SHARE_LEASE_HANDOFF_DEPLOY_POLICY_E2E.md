# v1.6.71 PWA Share Lease, Update Handoff, Deploy Policy, and E2E

## Problem set

This patch completes the eight requested follow-ups: real Chromium share flows, storage failure recovery, Android payload boundaries, deployed App Check parity, production audits, service-worker update handoff, main-module extraction, and same-ID multi-tab exclusion.

## Share ownership

Each share record has a short owner lease. Claim, heartbeat, release, and completion are IndexedDB transactions. Only the current owner can delete a completed record. A competing tab receives `claimed-by-other-tab`; an expired owner can be recovered after the lease expires.

## Storage and update recovery

The shared policy enforces 12 files, 220 MiB per file, 512 MiB per batch, 768 MiB retained storage, 8 records, and a 24-hour TTL. Storage estimate pressure and `QuotaExceededError` trigger safe cleanup and one retry without pruning active claims. Service-worker activation releases expired claims before claiming clients and broadcasts handoff readiness.

## App Check deployment contract

`app-check-policy.json`, `functions/app-check-policy-contract.json`, the client runtime policy, and the Functions helper use contract version 2. `appcheck:policy:check` verifies source parity. `appcheck:deploy:verify` compares the deployed public policy and Callable status metadata after Hosting and Functions deployment. Enforcement remains disabled; this release prevents silent drift.

## Browser acceptance

Actual system Chromium verified successful import, transient failure followed by reload retry, single import under two-tab contention, forced IndexedDB deletion and recreation, exact Android 12-file/512 MiB acceptance with overflow rejection, and service-worker activation handoff. The reproducible Playwright specification ships in `qa/browser/pwa-share-lease-handoff-playwright.spec.js`.

## Structural result

Service-worker registration, cache warming, update coordination, and share-launch orchestration moved to `src/boot/pwa-runtime-bridge.js`. `src/app.js` is 13,242 lines, below the 13,300-line gate. Audio mastering behavior is unchanged.
