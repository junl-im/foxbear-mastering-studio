# v1.6.92 AI Spectrum Panel Mount Lifecycle Recovery

## Incident

The detail panel rendered the AI Spectrum View shell, axis, and labels, but the canvas contained no FFT bars. The spectrum visualizer assigned a freshly created canvas to runtime state and immediately called the static renderer before the caller appended the panel to the DOM. The renderer's disconnected-canvas pruning treated that valid pre-mount canvas as stale and cleared the state reference.

## Recovery

- Mark the newly created spectrum canvas as pending mount.
- Do not perform the first FFT draw while the canvas is detached.
- After the render caller appends the panel, clear the pending flag and activate the spectrum path.
- If playback is idle or paused, render the analysis-time 24-band FFT profile.
- If playback is active, use an already registered analyser when available or the non-invasive capture-stream live FFT path; unsupported paths fall back to the static profile.
- Expose mount/draw diagnostics so blank-panel incidents can be distinguished from live analyser restrictions.

## Regression contract

`qa/v1692_spectrum_panel_mount_lifecycle_smoke.js` constructs the panel detached, verifies that it is protected rather than pruned, mounts it, runs the deferred activation, and requires a successful 24-band static draw with painted canvas content.
