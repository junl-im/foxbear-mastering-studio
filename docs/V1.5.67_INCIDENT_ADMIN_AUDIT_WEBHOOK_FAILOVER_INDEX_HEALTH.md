# v1.5.67 Incident Admin Audit, Webhook Failover, Index and Health Verification

## 진행 범위

- 관리자 단일 재전송, 일괄 복구, 경보 테스트, 배포 검증의 시작·거부·완료·실패를 `incidentAdminAuditLog`에 기록합니다.
- 감사 로그는 요청 ID, 축약 가능한 대상 식별자, 결과 집계만 저장하며 오류 원문·웹훅 URL·Gmail Secret은 저장하지 않습니다.
- 기본 웹훅은 제한된 횟수로 재시도하고 실패하면 `FOXBEAR_INCIDENT_ALERT_WEBHOOK_FALLBACK_URL`로 장애 전환합니다.
- 배포 검증은 실제 복합 쿼리를 실행해 incidentReports와 incidentOperationsHistory 인덱스 배포 상태를 확인합니다.
- 운영 이력은 상태·원인 필터와 커서 기반 페이지 처리를 지원합니다.
- `verifyIncidentPostDeployHealth`가 6시간마다 Functions 버전, SMTP, 웹훅, 인덱스, 최근 운영 점검 상태를 종합 확인합니다.

## 보안·운영 제한

- 웹훅은 허용된 HTTPS 호스트만 사용하고 URL은 Firestore나 관리자 UI에 기록하지 않습니다.
- Firestore 인덱스 생성은 배포 직후 빌드 중 상태일 수 있으므로 검증 결과가 `missing`이면 Console에서 Enabled 전환 후 다시 검사합니다.
- 실제 SMTP·웹훅 수신과 Firebase 인덱스 상태는 실제 프로젝트 배포 권한이 있는 환경에서 최종 확인해야 합니다.
