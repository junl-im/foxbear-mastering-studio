# v1.5.72 다중 곡 흐름·관리자 감사·모바일 UI

## 진행 목표

여러 곡을 불러오고 마스터링할 때 다음 단계가 명확하게 이어지도록 작업 흐름을 정리하고, 관리자 운영 화면을 간소화·검색·모바일 상세 조회에 맞게 개선합니다.

## 주요 변경

- 여러 곡의 분석이 모두 끝나면 대량 분석 팝업을 자동으로 숨기고 `전체 마스터링` 작업 영역으로 스크롤·포커스 이동합니다.
- 분석 오류가 일부 있어도 성공·오류 수를 안내하고 가능한 전체 마스터링 단계로 이동합니다.
- 여러 곡 마스터링 중에는 단일 곡용 처리 HUD를 표시하지 않습니다.
- 곡 목록 팝업에서 현재 진행 곡, 처리 단계, 곡별 진행률, 완료·오류 결과를 계속 표시합니다.
- 현재 곡이 바뀌면 목록이 해당 행으로 자동 이동하며 `aria-current=step`으로 접근성 상태를 제공합니다.
- 단일 곡을 다시 마스터링할 때 과거 대량 작업 소속 정보가 남아 단일 HUD가 숨겨지는 문제를 방지합니다.
- 관리자 화면에 간소화 보기, 24시간 초과 미확인 테스트 보존형 정리, 감사 로그 검색·상태 필터·페이지 처리·CSV 내보내기를 추가합니다.
- 미확인 테스트 정리는 문서를 삭제하지 않고 관리자 정리 상태와 처리 시각을 기록합니다.
- 메일 테스트 이력과 감사 로그는 720px 이하에서 표 대신 라벨이 있는 카드형 상세 화면으로 표시됩니다.

## 운영 확인

- 2곡 이상 업로드 후 모든 분석이 끝나면 분석 팝업이 숨겨지고 전체 마스터링 버튼이 강조·포커스되는지 확인합니다.
- 여러 곡 전체 마스터링 중 단일 `마스터링 중` HUD가 나타나지 않고 목록에서 현재 곡이 강조되는지 확인합니다.
- 완료 곡은 `완성`, 실패 곡은 `오류`, 현재 곡은 `현재 진행`으로 누적 표시되는지 확인합니다.
- 관리자 간소화 보기 상태가 브라우저 재진입 후 유지되는지 확인합니다.
- 24시간 초과 미확인 테스트 정리 후 기록이 삭제되지 않고 `관리자 정리`로 표시되는지 확인합니다.
- 감사 로그 검색·필터·추가 조회와 CSV 내보내기 결과가 화면 표시와 일치하는지 확인합니다.

## 제한 사항

실제 다중 마스터링의 장시간 렌더링, Firebase Functions 실행, Gmail 실수신, 모바일 브라우저 시각 비교는 배포 및 실제 브라우저 환경에서 최종 확인해야 합니다.
