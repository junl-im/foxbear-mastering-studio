# v1.5.85 Browser Fixture Preflight & Root-Cause Diagnostics

## Problem

The browser gate could spend several minutes launching every desktop/mobile viewport before reporting the same source-level fixture violation repeatedly. Visual specs also duplicated DOM construction, increasing drift risk between test variants.

## Changes

- Added `qa/browser/helpers/visual-fixture-builders.js` with self-contained builders for the bulk mastering HUD and mobile download sheet.
- Added semantic progress and selected-state ARIA while preserving the production CSS classes used by the visual contracts.
- Added `qa/browser/spec-preflight.js`, which scans browser QA before Playwright startup for HTML parsing sinks and string-based evaluation.
- Added grouped failure diagnostics in `qa/browser/run-browser-e2e.js` with stable root-cause codes and actionable remediation.
- Added `qa/v1585_browser_fixture_preflight_diagnostics_smoke.js` to verify preflight rejection and ten-to-one Trusted Types failure grouping.

## Verification

```bash
node qa/browser/spec-preflight.js
node qa/v1584_trusted_types_browser_qa_smoke.js
node qa/v1585_browser_fixture_preflight_diagnostics_smoke.js
npm run check
```

Actual Chromium layout execution still requires installed Playwright and Chromium binaries.
