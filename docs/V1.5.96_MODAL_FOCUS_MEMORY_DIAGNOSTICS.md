# v1.5.96 Modal Focus, Scroll Lifecycle, and Memory Diagnostics

- Centralizes opener memory, focus restoration, Tab cycling, Escape handling, backdrop dismissal, and mobile scroll locking in the shared modal controller.
- Registers the program information and incident-reporting dialogs in the common controller instead of relying only on local handlers.
- Keeps dynamically created performance diagnostics in the same shared layer lock and restores focus to the settings button after close.
- Replaces the diagnostics-only raw text view with readable status cards for browser memory, audio playback, Worker jobs, long tasks, and retained PCM; technical data remains available in an expandable log.
- Reduces automatic diagnostics refresh frequency from 1.2 seconds to 2.5 seconds to lower monitoring overhead.
