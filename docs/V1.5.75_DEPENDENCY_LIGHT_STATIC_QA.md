# v1.5.75 Dependency-Light Static QA

## Problem

Several static regression checks imported `qa/browser/run-browser-e2e.js` only to test helper functions. The runner resolved `@playwright/test/cli` at module load time, so a clean source handoff without `node_modules` caused five non-browser checks to fail before their assertions ran. `playwright.config.js` had the same eager dependency for a configuration metadata probe.

## Fix

- Resolve the Playwright CLI lazily inside the browser QA entrypoint.
- Return a stable `FOXBEAR_PLAYWRIGHT_DEPENDENCY_MISSING` diagnostic with `npm ci` and browser-install recovery commands.
- Keep `playwright.config.js` import-safe through minimal desktop/mobile fallback descriptors when the Playwright package itself is absent.
- Continue using official Playwright `defineConfig` and `devices` whenever the dependency is installed.

## Regression contract

`qa/v1575_dependency_light_static_qa_smoke.js` simulates a missing Playwright package, verifies configuration probing still works, confirms helper imports remain available, and validates the actionable dependency error.

## Verification boundary

This patch verifies static behavior and dependency diagnostics. Real Chromium browser execution still requires an installed `@playwright/test` package and browser binary in CI or a development environment.
