# v1.6.86 Header Order + Mobile Overflow Browser Gate Recovery

## Trigger

GitHub Actions run `31369987741` repeated the Runtime Health sentinel failure in both projects. Desktop reported `modeSwitchLeft=1112.8125` against an expected minimum of `1356`; mobile reported `rowOverlap=135.28125` against a maximum of `1`.

## Root cause

The desktop command bar still inherited an old `order: 2` rule for `.designer-mini`, so the creator link rendered after newly inserted workspace/settings controls even though the DOM placed it first. On Pixel-class widths the creator token was also nonessential pressure inside the fixed right-action group, leaving the left BUILD/device group insufficient room.

## Fix

- Reset `.brand-command-bar .designer-mini` to `order: 0 !important`.
- Hide the creator token at `max-width: 430px`; keep workspace mode and settings controls visible.
- Preserve the 40px mobile workspace switch target.
- Keep Runtime Health geometry thresholds unchanged.
