# v1.6.12 Mastering Tone and Loudness Fast Path

## 목적

v1.6.11에서 중복 True Peak 및 K-weighted 필터 패스를 제거한 뒤 남은 병목은 공진 보호, dynamic de-esser, 3-band dynamics로 구성된 `toneDynamics` 단계였습니다. 이번 패치는 처리 순서와 DSP 수식을 바꾸지 않고 JavaScript 실행 오버헤드와 전체 버퍼 순회를 줄입니다.

## 변경 사항

- 모노와 스테레오를 각각 전용 루프로 처리해 샘플마다 반복되던 채널 배열 순회와 scratch 객체 읽기/쓰기를 제거했습니다.
- biquad 상태는 전용 processor closure가 보유해 반복적인 상태 객체 속성 접근을 줄였습니다.
- K-weighted 필터 결과를 채널별 Float32 배열로 보관하는 대신, 기존 Float32 반올림 경계를 `Math.fround`로 유지한 샘플별 Float64 전력 배열로 집계합니다.
- Integrated LUFS와 Short-term LUFS는 동일 전력 배열을 공유합니다.
- 입력 검사와 sanitize, 최종 DC 제거와 sanitize를 각각 하나의 전체 버퍼 순회로 결합했습니다.
- Worker 복구 시 사용되는 메인 스레드 fallback도 최종 LUFS/Short-term 측정을 공유합니다.

## 불변 조건

- 모바일 공진 보호 → dynamic de-esser → multiband dynamics 순서는 유지합니다.
- 채널별 필터 호출 순서, 스테레오 링크 detector 갱신 순서, Float32 출력 저장 순서를 유지합니다.
- 같은 입력에 대해 v1.6.11과 v1.6.12의 출력 Float32 샘플, 최종 LUFS, True Peak, limiter 및 dynamics telemetry가 동일해야 합니다.
