# v1.5.77 Runtime Resource Lifecycle Recovery

## Fixed

- Spectrum audio registrations now keep removable listener references and explicitly release captured media streams, analyser nodes, and owned AudioContext resources.
- Detached audio elements are pruned by a DOM lifecycle observer and can also be removed immediately through `unregisterAudio`.
- Non-BFCache page exits dispose spectrum resources; BFCache restores restart only the active mounted visualizer.
- Waveform comparison transport intervals expose deterministic disposal and are released as soon as the dialog body is cleared.
- Preview and Dock cleanup explicitly unregister audio from both spectrum and playback-link registries.
- Mobile settings panel positioning reacts to `visualViewport` resize/scroll events and falls back safely when `requestAnimationFrame` is unavailable.

## Verification

- Syntax checks for all changed runtime modules.
- VM-based regression test verifies detached audio listeners are removed and lifecycle listeners are released by disposal.
- Static contracts verify popup timer disposal, preview cleanup integration, and mobile visual viewport handling.
