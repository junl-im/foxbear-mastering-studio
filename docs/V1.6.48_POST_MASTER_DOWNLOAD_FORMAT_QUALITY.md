# v1.6.48 Post-Master Download Format and Quality

## Problem

The download dialog exposed MP3 and WAV choices, but the memory guard released the completed PCM buffer on mobile, low-memory, batch, and restricted-browser paths. Once released, every non-current output format became unavailable and users were told to remaster.

## Patch

- Reuse the existing output Blob when the selected format matches the mastered format.
- Use the retained completed PCM buffer when available.
- Otherwise decode the completed mastered output Blob and re-encode it to the selected MP3 bitrate or WAV bit depth.
- Keep conversion local to the download action and release the temporary decoded buffer after encoding.
- Add an always-visible native quality selector and make MP3/WAV family selection effective immediately.
- Warn when a lossy MP3 master is converted to WAV because the conversion does not restore lost detail.

## Supported download choices

- MP3: 128, 192, 256, 320 kbps
- WAV: 16-bit PCM, 24-bit PCM, 32-bit float

## Regression coverage

`qa/v1648_download_post_master_format_quality_smoke.js` verifies option availability, completed-output decoding, selected-quality encoding, progress mapping, file naming, UI wiring, and the MP3-to-WAV warning.
