# v1.5.94 AIFF Fallback, Worker Diagnostics, and Reporting Contract

## AIFF fallback safety

Native decode cancellation and timeout errors are terminal. The synchronous AIFF PCM parser is limited to 16 Mi channel-samples so a failed browser decoder cannot move a large file onto a blocking main-thread fallback.

## Worker failure diagnostics

Recent Worker records preserve error name, error code, cancellation reason, last progress timestamp, and progress age for completed terminal states.

## Persistent result format

Every future patch report uses only these sections unless the user explicitly requests another format:

1. 진행된 내용
2. 배포 파일 2종
3. 다음 패치 예정 라인업
