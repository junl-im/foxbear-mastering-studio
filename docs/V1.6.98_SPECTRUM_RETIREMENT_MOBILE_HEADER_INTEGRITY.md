# v1.6.98 - Spectrum retirement and mobile header integrity

## Problem

The user-facing AI Spectrum View was no longer providing useful value, while its runtime still added a visualization module, stylesheet, diagnostics bookkeeping, and Web Audio analyser taps to several playback graphs. Separately, the mobile AI workspace CSS hid the entire PC/phone compatibility token, so the header glyph disappeared when switching to AI mode on compact screens.

## Change

- Delete the AI Spectrum View JS/CSS and remove its Detail renderer.
- Remove Spectrum Visualizer requirements from Runtime Health and Performance Diagnostics.
- Remove visualization-only analyser taps from realtime preview, difference listening, and preview-translation graphs.
- Preserve offline/worker spectral analysis used by mastering decisions.
- Stop mobile AI mode from hiding `.brand-command-device`; compact header CSS may hide only `.brand-command-device-text`.

## Regression contract

`qa/v1698_spectrum_retirement_mobile_header_integrity_smoke.js` requires the retired UI assets and runtime globals to remain absent, requires mastering spectral analysis to remain present, and requires the PC/phone icon token to stay available in mobile AI mode.
