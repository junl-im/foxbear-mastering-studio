# v1.6.114 Reference Profile 64-band Upgrade

## Scope

This release activates the previously prepared 64/96-band reference-profile foundation for uploaded reference tracks while retaining the existing 24-band compatibility path. Normal preset-only mastering keeps the legacy 24-band matching behavior.

## High-resolution reference analysis

The analysis Worker now emits the established 24-band compact spectrum plus a normalized 64-band logarithmic profile from 20 Hz to 20 kHz. Uploaded reference targets retain both representations.

## Matching behavior

When both the uploaded reference and the current track contain native 64-band analysis, reference-band deltas use frequency-addressed 64-band regions for sub, bass, mud, body, vocal, presence, harshness, sibilance, air, and spectral tilt. Legacy or preset-only paths fall back to the existing 24-band logic.

## Profile normalization fix

The dormant reference-profile helper had a same-size normalization gap: a profile already matching the requested band count was clamped but not sum-normalized. The helper now normalizes both resampled and same-size profiles consistently.

## Regression

`qa/v16114_reference_profile_64band_upgrade_smoke.js` verifies the Worker contract, high-resolution reference gating, legacy fallback, 64 log bands, and unit-energy normalization.
