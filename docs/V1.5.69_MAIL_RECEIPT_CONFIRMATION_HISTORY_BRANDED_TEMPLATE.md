# v1.5.69 메일 실수신 확인·이력·통합 디자인

## 목표

- SMTP 접수와 실제 받은편지함·스팸함 도착 확인을 분리해 기록한다.
- 마지막 성공·실수신 확인 시각을 관리자 화면에 표시하고 7일 이상 검증하지 않으면 경고한다.
- 실제 메일 테스트 결과를 90일 이력으로 보존한다.
- 테스트, 오류 신고, 운영 경보, 복구, 일일 요약 메일의 HTML 디자인을 하나의 브랜드 템플릿으로 통일한다.

## 운영 절차

1. 설정에서 `실제 메일 테스트`를 실행한다.
2. Gmail SMTP 접수 완료와 Message-ID를 확인한다.
3. Gmail에서 제목을 검색하고 도착 위치를 확인한다.
4. 관리자 오류 화면에서 `받은편지함 수신 확인` 또는 `스팸함 수신 확인`을 누른다.
5. `incidentOperations/mailVerification`과 `incidentMailTestHistory`에서 확인 시각과 위치를 검증한다.

## 보존 및 보안

- 테스트 이력은 90일 TTL을 사용한다.
- 관리자 확인 요청은 활성 관리자만 생성·조회할 수 있다.
- 오디오, 파일명, 원본 PCM, Gmail Secret은 테스트 이력과 메일 본문에 포함하지 않는다.

## 검증

- 정적·회귀 검사 278개를 구간별로 실행해 모두 통과한다.
- 실제 Chromium 실행과 Gmail 받은편지함 배치는 배포 환경에서 별도 확인한다.
