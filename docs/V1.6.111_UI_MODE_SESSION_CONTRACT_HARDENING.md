# v1.6.111 UI Mode Session Contract Hardening

## Contract

- Same tab/window reload: restore the selected AI/Expert mode from `sessionStorage`; do not reopen the required chooser.
- Fresh independent browsing session: start `unselected` and require a new choice.
- Manual work-mode switch: reopen the chooser as an optional dialog and keep the current mode if dismissed.

## Diagnostics

`FoxBearUiModeController.getSnapshot()` reports `restoredSource` (`session`, `pending`, `e2e`, or `unselected`) plus the exported `SESSION_CONTRACT`.

## Browser regression

Runtime Health Playwright coverage performs a real same-tab reload, reopens and switches mode from the header, then opens a fresh BrowserContext and verifies that no prior session mode leaks into it.
