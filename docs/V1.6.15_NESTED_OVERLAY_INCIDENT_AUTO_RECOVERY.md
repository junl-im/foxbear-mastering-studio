# v1.6.15 Nested Overlay and Incident Auto-Recovery

## Scope

This release generalizes the viewport-safe download quality popup into a shared overlay policy and adds bounded self-recovery to anonymous Firebase incident reporting.

## Conditional nested overlay policy

- A modal opened from the normal page replaces the current top-level modal as before.
- A modal, selector, help panel, or secondary action opened from inside an active dialog is treated as a nested layer when that relationship is detectable.
- Nested layers are moved into the shared fixed-overlay stack instead of expanding the parent layout.
- The parent remains mounted but is temporarily inert so focus and pointer input cannot leak behind the child.
- The active visual viewport supplies top, left, width, and height variables. Each panel is height-limited and scrolls internally on short mobile screens.
- Closing the child restores the parent layer and focus target. Body scroll remains locked until every blocking layer has closed.
- Floating assistance panels may opt out of scroll locking while still receiving viewport containment and z-order management.

## Incident self-recovery

- The endpoint probe first performs the normal readable CORS request.
- When the readable request fails, a privacy-safe `no-cors` probe distinguishes an endpoint that is reachable but unreadable from a true network failure.
- Offline state, endpoint response blocking, function absence, server internal failure, and CSP/network failure are displayed separately.
- Transient failures are rechecked after 5, 15, and 45 seconds, with a maximum of three automatic attempts.
- Returning online triggers a fresh service check and retries the local anonymous-report queue.
- A manual recovery action checks the service, retries queued reports, and optionally runs deployment readiness diagnostics.
- The diagnostic-copy action exports only sanitized version, endpoint state, CSP result, App Check flags, retry counters, and deployment check summaries. It excludes audio, filenames, local paths, and report payloads.
