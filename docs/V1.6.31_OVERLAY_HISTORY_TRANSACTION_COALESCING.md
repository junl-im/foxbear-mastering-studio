# v1.6.31 Overlay History Transaction Coalescing

## Problem

A normal dialog close removes its history sentinel with `history.back()`. If the user immediately reopened and closed another dialog before the first popstate arrived, the old implementation could request a second internal Back traversal. That second traversal could pass the overlay sentinel and reach the workspace exit guard, producing an unexpected Back/exit message.

## Changes

- Internal sentinel release remains single-flight until popstate settlement.
- Repeated release requests are coalesced and counted without issuing another history traversal.
- If a dialog is open when the pending release settles, one new sentinel is pushed.
- The modal controller exports bounded history diagnostics.
- The exit guard classifies internal release, open-overlay, overlay-handled, and genuine workspace Back events.
- Performance diagnostics collect these counters without URLs, filenames, audio, report contents, or identifiers.
