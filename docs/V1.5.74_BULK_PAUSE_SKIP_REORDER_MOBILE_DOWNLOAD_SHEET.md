# v1.5.74 다중 작업 제어 및 모바일 다운로드 시트

## 진행 내용

- 현재 곡 완료 후 다음 곡 직전 일시정지·계속 진행
- 현재 곡만 안전하게 건너뛰기
- 시작 전 대기 곡 순서 변경
- 배치 완료 결과와 소요 시간 요약
- 모바일 다운로드 모달을 94dvh 하단 시트로 확장
- MP3/WAV 형식 선택 후 세부 품질 선택
- 모바일 저장·공유 기본 작업 하단 고정

## 안전 규칙

- 일시정지는 현재 곡의 오디오 작업을 중단하지 않습니다.
- 건너뛰기는 전체 배치가 아닌 현재 곡 신호만 취소합니다.
- 완료 결과는 유지하고 대기 곡만 재정렬합니다.
- 다른 포맷 PCM이 해제된 경우 기존처럼 재마스터링 필요 상태를 표시합니다.

## 배포 후 확인

- 375px 및 430px 모바일 화면에서 다운로드 버튼 가림 여부
- MP3/WAV 전환 및 품질 선택 상태
- 일시정지 중 다음 곡 미시작 여부
- 건너뛰기와 대기열 순서 적용 여부
