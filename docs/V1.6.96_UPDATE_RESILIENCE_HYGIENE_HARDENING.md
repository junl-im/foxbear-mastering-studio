# v1.6.96 Update Resilience & Hygiene Hardening

## Scope

- Active-client-aware Service Worker cache retirement.
- Minimum recovery-shell install gate with best-effort optional boot caching.
- Git-index-aware source-hygiene enforcement for pending deletions.
- Release description metadata synchronization.
- Server-configured incident recipient presentation.

## Safety contracts

- A non-responsive active window defers legacy shell cache retirement.
- A reported active legacy cache is never deleted by the current activation cleanup.
- Optional install asset failures are recorded but do not reject Service Worker installation.
- A forbidden tracked file remains a hygiene failure until its deletion leaves the Git index.
