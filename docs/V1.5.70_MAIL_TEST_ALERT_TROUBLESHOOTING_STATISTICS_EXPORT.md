# v1.5.70 메일 테스트 자동 경보·점검 마법사·통계·내보내기

## 목적

실제 오류가 발생하지 않는 기간에도 메일 경로가 정상인지 지속적으로 확인하고, SMTP 접수와 Gmail 실수신 사이의 누락을 운영자가 즉시 식별할 수 있도록 한다.

## 변경 내용

- 15분 운영 점검에 실제 메일 테스트 상태를 포함한다.
- 한 번도 테스트하지 않은 상태, 마지막 실수신 확인 후 7일 경과, 최근 테스트 실패를 경보 원인으로 기록한다.
- SMTP 접수 후 30분이 지나도 받은편지함 또는 스팸함 확인이 없는 테스트를 누락으로 추적한다.
- 이전에 실수신 확인된 시각보다 오래된 미확인 테스트는 현재 장애로 집계하지 않는다.
- 관리자 화면에 최근 100건 기준 SMTP 성공률, 실수신 확인률, 받은편지함/스팸함 분포, 30분 초과 미확인 건수를 표시한다.
- 최근 실패 사유에 따라 Gmail Secret, 일일 한도, 수신 거부, Gmail 필터, Functions 로그 점검 순서를 자동 안내한다.
- 제목, Message-ID, 보고서 ID, 테스트 ID, 상태를 검색하고 필터링된 결과를 UTF-8 CSV로 내보낼 수 있다.

## 운영 기준

- 실제 메일 테스트 권장 주기: 7일 이내 1회
- SMTP 접수 후 실수신 확인 제한: 30분
- 이력 조회 범위: 최근 100건, 최대 200건 렌더링
- 자동 운영 점검 주기: 15분
- 운영 경보 재발송 제한: 기존 12시간 쿨다운 유지

## 배포 후 확인

1. Firestore Rules, Functions, Hosting을 같은 버전으로 배포한다.
2. 설정 화면에서 실제 메일 테스트를 실행한다.
3. SMTP 접수 시각과 Message-ID를 확인한다.
4. Gmail에서 `subject:"[AI마스터링 스튜디오][메일 테스트]"`를 검색한다.
5. 받은편지함 또는 스팸함 위치를 관리자 화면에 기록한다.
6. 통계 카드의 SMTP 성공률과 실수신 확인률이 갱신되는지 확인한다.
7. 검색과 CSV 내보내기가 현재 필터 결과만 포함하는지 확인한다.
