# v1.5.88 Browser Impact Selection and Flaky History

## Summary

This patch reduces unnecessary Browser release gate cost while keeping a conservative safety fallback. A dependency-light impact selector classifies the changed files before `npm ci` and Chromium installation, then skips browser execution for documentation/backend/static-only changes, selects known related specs for narrowly mapped UI changes, or promotes unknown/core changes to the complete suite.

The failed-only retry report now also updates a cached flaky-history ledger. Repeated retry recoveries, repeated failures, and missing retry outcomes are preserved across GitHub Actions runs and surfaced in JSON, Markdown, annotations, and the Job Summary.

## Browser impact modes

- `skip`: documentation, Functions-only, packaging-only, or dependency-light static QA changes.
- `selected`: directly changed browser specs or production files covered by a known impact map.
- `full`: core runtime/security/PWA/test infrastructure changes, missing diff information, or any unmapped browser-observable file.

The selector writes `qa/browser-results/browser-impact.json` and GitHub outputs for `run_browser`, `mode`, `specs`, `changed_count`, and `reason`.

## Cumulative flaky history

- Cache source: `qa/browser-history/flaky-history.json`
- Artifact summaries:
  - `qa/browser-results/flaky-history-summary.json`
  - `qa/browser-results/flaky-history-summary.md`
- Default recurring-flaky warning threshold: three retry recoveries for the same stable spec/title/project key.
- Latest repeated or missing retry results remain classified as unresolved.
- The history directory is ignored by Git and excluded from release and overwrite ZIP files.

## Safety behavior

- Missing or truncated changed-file information defaults to the complete browser suite.
- Unknown CSS/runtime changes default to the complete browser suite.
- `--last-failed` retry ignores impact-selected targets and uses only Playwright's stored failed-case state.
- Explicit browser spec arguments continue to override impact selection.
