# v1.6.64 GitHub Desktop Delivery Artifact Contract

## 목적

소스 저장소 자체를 임의로 압축할 때 `.git`, Firebase CLI 캐시, 실제 프로젝트 선택 파일, 생성 QA 로그가 포함되는 문제를 차단하고, 사용자 전달 형식을 전체 ZIP과 덮어쓰기 패치 ZIP 두 종류로 고정한다.

## 변경 사항

- `npm run package:delivery`가 다음 두 파일을 생성한다.
  - `foxbear-mastering-studio-v1.6.64-full.zip`
  - `foxbear-mastering-studio-v1.6.64-patch.zip`
- full ZIP은 전체 프로젝트 전달본이며 Git 메타데이터, 로컬 Firebase 상태, 의존성 설치 결과, 테스트 결과와 비밀 환경 파일을 제외한다.
- patch ZIP은 v1.6.63 기준 이번 릴리스 변경 파일만 담으며 해당 저장소 루트에 바로 풀 수 있다.
- `PATCH_NOTES.md`와 `DELETE_PATHS.txt`를 두 전달본에 포함한다.
- `source:hygiene` 검사는 금지 파일이 Git에 추적되거나 비-Git 전달본에 포함되면 실패한다.
- 정적 릴리스 게이트는 버전·인수인계 검사 전에 소스 위생 검사를 실행한다.

## 삭제 대상

압축 해제만으로 삭제할 수 없는 기존 로컬 파일은 `DELETE_PATHS.txt`로 명시한다. 대표 대상은 `.firebaserc`, `.firebase/`, `.audit-results/`, 생성 QA 텍스트다.

## 호환성

기존 `-release.zip`, `-overwrite.zip` 생성·검증 흐름은 내부 호환성을 위해 유지한다. 사용자 전달 파일은 별칭인 `-full.zip`, `-patch.zip`만 사용한다.
