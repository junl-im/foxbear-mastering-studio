# v1.6.53 Playback Crossfade Settlement Guard

## Audit findings

The v1.6.52 post-master readiness patch stabilized the first Play tap, but the original/mastered source-switch path still had two independent edge cases:

1. A user-gesture crossfade called `nextAudio.play()` immediately, then the parallel media-readiness waiter called `nextAudio.load()` while metadata was still pending. On KakaoTalk and some mobile WebViews, the new load could abort the play request that had just consumed the user activation.
2. `crossfadePair()` deliberately resolves `false` for cancelled, detached, or superseded transitions. The Dock caller only handled rejected promises, so a resolved-false transition could retain the legacy player and the `is-crossfading` class indefinitely.

The second condition could leave two audio elements in the Dock, stale player ownership, an incorrect external Play state, or later source switches selecting the wrong child.

## Patch

### Non-destructive user-gesture readiness

- `waitForMediaReady()` now accepts an explicit `load` option.
- User-gesture crossfades issue `play()` immediately and wait for `canplay`/`loadeddata` without calling `load()` in parallel.
- Non-gesture and interrupted-play recovery paths may still call `load()` when a controlled reload is needed.
- The existing bounded readiness timeout and interruption retry remain unchanged.

### Terminal crossfade settlement

- The Dock observes both promise rejection and a normal `false` result.
- Every terminal path removes the legacy player, clears `is-crossfading`, and releases the next player's old-audio reference.
- Successful transitions synchronize the external Play control to the active playing audio.
- Cancelled or stale transitions clean up without forcing playback back on.
- Thrown transition errors may retry only through the audio element that is still the active Dock source.
- Settlement is idempotent so `onComplete` and promise resolution cannot clean up twice.

### Small integrity cleanup

- Removed a duplicated mastered-source availability guard.
- Kept `src/app.js` below the historical 13,300-line contract.
