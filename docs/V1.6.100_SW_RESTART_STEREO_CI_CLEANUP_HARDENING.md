# v1.6.100 SW restart, stereo analysis, and CI cleanup hardening

## Problems closed

- A restarted Service Worker could forget active-client generation reports and fail to find an exact old asset even though its shell cache still existed.
- Client-aware retirement declared two rollback generations but protected only the latest one.
- Multichannel input could be analyzed with more than two channels while final mastering rendered no more than two.
- Retired AI Spectrum UI files could survive an overwrite-only patch and fail a dozen later regression tests instead of failing early.
- GitHub Desktop-only Windows environments could complete file deletion but fail the final hygiene check only because `git` was absent from PATH.

## Policy

Exact stale asset requests search every `foxbear-shell-*` cache. Cache retirement still remains conservative and client-aware. Analysis semantics are mono/stereo by design to match the mastering output path. Retired Spectrum UI assets are forbidden source state.
