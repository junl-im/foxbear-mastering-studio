# v1.6.14 Download Quality Memory, Size Estimate, and Adaptive Position

## Goal

Keep the mastered-file download flow compact while ensuring the MP3/WAV quality menu never pushes or escapes the visible screen.

## Changes

- Keeps only MP3 and WAV visible in the download sheet.
- Renders the quality list as a fixed portal above the scrollable download panel instead of as panel content.
- Uses `visualViewport` dimensions and offsets to clamp all four menu edges to the currently visible screen.
- Opens below or above the selected family button according to available space.
- Limits menu height to the visible viewport and enables internal scrolling when necessary.
- Expands the mobile download sheet to at most `96dvh` and keeps its contents internally scrollable.
- Persists the last valid MP3 bitrate, WAV bit depth, and last selected format in guarded local storage.
- Shows exact size for the already-generated output and estimates alternate MP3/WAV sizes from duration, sample rate, and channel count.

## Safety and Compatibility

- No encoder or mastering DSP behavior changes.
- Invalid or unavailable stored preferences fall back to MP3 320 kbps and WAV 24-bit.
- The portalled menu is removed and all viewport listeners are detached when the dialog closes.
- Existing keyboard, outside-click, Escape, share, save-assist, cancel, and recovery behavior remains intact.

## Regression

Run:

```text
node qa/v1614_download_quality_memory_size_position_smoke.js
```
