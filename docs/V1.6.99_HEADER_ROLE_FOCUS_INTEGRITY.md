# v1.6.99 Header Role / Focus Integrity

## Why

The header compatibility glyph and administrator monitor previously shared one DOM element. Admin authentication could therefore replace the PC/mobile glyph with admin text, recreating the apparent “missing device image” regression even after the AI-mode CSS fix.

## Changes

- `deviceCompatibilityBadge` is now static, non-interactive compatibility status markup.
- `adminStatsTrigger` is a separate native button shown only for authenticated administrators.
- Native button keyboard activation relies on browser semantics; the old synthetic Enter/Space handler is removed.
- Closing the administrator monitor restores focus only when the original target still exists and is visible.
- Compact mobile styling keeps the separate admin action from squeezing the compatibility glyph.
