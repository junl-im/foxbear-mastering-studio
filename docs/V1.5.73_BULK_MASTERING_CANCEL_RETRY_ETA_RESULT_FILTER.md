# v1.5.73 다중 마스터링 취소·재시도·ETA·결과 필터

## 목적

다중 곡 마스터링 중 사용자가 안전하게 작업을 중단하고, 성공 결과를 보존한 채 실패 곡만 다시 실행할 수 있도록 한다. 진행 목록은 현재 작업과 예상 완료 시간을 한 화면에서 제공한다.

## 구현

- 배치 러너는 활성 `AbortController`와 배치 스냅샷을 관리한다.
- 취소 신호는 현재 `masterTrack`의 워커·파이널라이저·인코더 신호로 전달된다.
- 현재 곡과 아직 시작하지 않은 곡은 `cancelled`로 정리되며 완료·실패 결과는 유지된다.
- 실패 곡 재시도는 오류 상태만 초기화하고 새 배치 ID로 실행한다.
- 완료 곡의 실제 소요 시간을 기반으로 현재 곡 남은 시간과 대기 곡 완료 예상 시간을 계산한다.
- 결과 필터는 UI 표시만 변경하고 트랙 상태는 변경하지 않는다.

## 검증 제한

현재 작업 환경에는 실제 Chromium 실행 패키지가 없어 Playwright 시각 계약은 정적 포함 여부와 코드 계약까지 확인한다. 실제 취소 타이밍, 브라우저 메모리 회수, ETA 체감 정확도는 배포 후 실제 오디오 파일로 확인한다.

- 실제 Chromium 시각 검증은 배포 환경에서 별도 수행
