# v1.6.11 Mastering Speed Measurement Reuse

## 목표

마스터링 음질, 리미터 동작, LUFS, True Peak 결과를 유지하면서 메인 finalizer Worker의 불필요한 전체 버퍼 순회를 제거한다.

## 변경 사항

- Worker로 transfer된 채널 버퍼가 선언 길이와 같으면 추가 `Float32Array.slice()` 복사 없이 그대로 처리한다.
- 톤/다이내믹 처리 뒤 측정한 피크에 상수 게인을 곱해 pre-limiter 피크를 계산하고, 동일 신호에 대한 두 번째 4x FIR True Peak 순회를 제거한다.
- 최종 Integrated LUFS와 Short-term LUFS가 하나의 K-weighted 필터 결과를 공유한다.
- 안전 게인 적용 여부를 반영해 이미 확정된 `peakAfter`를 최종 피크로 재사용하고 마지막 중복 4x FIR True Peak 순회를 제거한다.

## 결과 보존

v1.6.10과 v1.6.11을 같은 1.5초 스테레오 합성 입력으로 비교한 결과:

- 출력 샘플 차이: `0`
- Integrated LUFS 차이: `0`
- 최종 LUFS 차이: `0`
- 최종 True Peak 차이: `0`
- Short-term LUFS 객체: 동일
- `preLimiterPeak` 텔레메트리만 Float32 게인 반올림 때문에 약 `4.5e-8`의 비가청 차이가 발생할 수 있다.

## 로컬 합성 벤치

Node VM에서 3초/44.1kHz/스테레오/4x True Peak 입력을 3회 실행했다.

- v1.6.10 중앙값: 약 `8.34초`
- v1.6.11 중앙값: 약 `4.98초`
- 중앙값 기준 처리 시간 감소: 약 `40%`
- 동일 장치의 실제 브라우저 성능은 엔진, CPU, 열 상태, 트랙 특성에 따라 달라질 수 있다.
