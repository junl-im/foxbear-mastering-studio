# v1.6.102 Admin lazy-load, Service Worker, and hygiene hardening

- Extract the administrator incident lazy loader from `src/app.js` into a small retry-safe service.
- Remove failed/stale dynamic script elements and enforce a bounded load timeout so a second attempt cannot hang forever.
- Keep the 77KB administrator incident monitor out of Service Worker install/background-warm graphs; it is fetched and cached only on first administrator incident-tab use.
- Make Service Worker installation wait only for the minimum recovery shell and warm the normal boot graph after activation.
- Centralize source-hygiene forbidden/repairable/patch-cleanup policy and make repair actually remove all allowlisted retired/helper paths.
- Retire root `README.txt` and block one-off `*_NO_GIT.cmd/.sh` helper artifacts from re-entering release source.
