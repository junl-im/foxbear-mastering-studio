# v1.6.0 Incident Mail Pipeline Health

- The incident settings dialog shows anonymous authentication, callable API, queue persistence, and SMTP acceptance as separate stages.
- A new authenticated `getIncidentServiceStatus` callable reports the deployed service version, region, schema, and App Check monitoring state.
- The client compares the deployed Functions version with the current web version and warns when the server is older.
- App Check remains in monitor/optional mode so anonymous incident reporting keeps working until a production site key is configured and verified.
- Manual mail testing reports the exact stage that is pending, delayed, failed, or accepted.
- Regression: `node qa/v1600_incident_mail_pipeline_health_smoke.js`.
