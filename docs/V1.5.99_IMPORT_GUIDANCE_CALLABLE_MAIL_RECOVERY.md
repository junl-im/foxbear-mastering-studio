# v1.5.99 Import Guidance and Callable Mail Recovery

## Import guidance

The upload notice now asks the user to load one or more mastering files without exposing codec implementation details in the primary interface. File picker filtering and runtime decode validation remain unchanged.

## Incident transport

Authenticated callable Functions are the primary transport for incident creation and delivery-status lookup. The server writes with the Admin SDK, so stale or restrictive client Firestore rules cannot block the real mail test. The previous create-first Firestore path remains as a compatibility fallback until both callable Functions are deployed.

## Deployment

`npm run deploy:incident` now deploys `submitIncidentReport` and `getIncidentDeliveryStatus` together with the existing mail trigger, rules, indexes, retries, and operations functions.
